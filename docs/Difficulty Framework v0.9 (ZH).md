## 1. 摘要

难度 = 挑战者把参考作品的"余量"打空的速度。

模型只有两个状态量，`E`（射精兴奋度）和 `r_th`（中性阈值）：

```
r ≥ r_th:  累积          dE/dt = +K·[(r − r_th)/(3 − r_th)]^1.2
r < r_th:  回落          dE/dt = −k_n·(1 − r/r_th)
r_th:      随兴奋即时下移  r_th = max(0, 1.0 − 2.0·(E − 0.5))
```

三条性质：

1. **阈值随 E 下移**：兴奋越高，"无感"的速率越低。E=1 时阈值恰好归零 → 碰一下就射。
2. **回落与 E 无关**：停止带来的放松是固定过程，不会因为你更兴奋而变快。
3. **回落按距离比例**：`r` 越接近阈值回落越弱，`r=0` 时拿满——消除了"低于阈值就按完全停止处理"的断层。

## 2. 公式

```
初始:
    E = 0.50          （平台期起点，余量一半）
    K = 0.000736 /s   （标定值，见 §4）

每步 dt:
    ① 阈值      r_th = max(0, 1.0 − 2.0·(E − 0.5))

    ② 累积（r ≥ r_th）
                E += K · [ (r − r_th)/(3.0 − r_th) ]^1.2 · dt

    ③ 回落（r < r_th，且 E < 1）
                E −= 2K · 0.85^n · (1 − r/r_th) · dt
                E 下限 0.5

    ④ 刹车档位 n
                单段休息 ≥1.5 s 才计入累计休息；开场（首次刺激前）不计
                累计休息 <10 s → n = 0
                累计休息 ≥10 s → n = 1 + ⌊(累计休息 − 10)/20⌋
                k = 2K · 0.85^n              ← 满 10 s 即用第一次修正

    ⑤ 主分      S = 100 · (E_终 − 0.5) / 0.5
```

**保留但当前关闭的项**：

```
A += α·(E − 0.5)·dt        （α=0 → A 恒为 0，本版不启用）
r_th = max(0, 1.0 − A − 2.0·(E−0.5))
```

`A` 是"阈值的长期累积下移"，设计上限 `1.0−γ`。α=0 时它不参与运算；
留这个接口是为了将来用"长时间低强度"的作品（比如 20 分钟的 HMV）再启用。

### 2.1 为什么阈值要归零

`β=2.0` 且 `r_th0=1.0` 时，`E=1` 恰好使 `1.0 − 2.0×(0.5) = 0`。
这不是刻意凑的，而是"**到点前最后一下必然失控**"这条生理事实的最小表达。

### 2.2 为什么刹车要按累计时长分档

Bustos 的每次刹车都是 25 秒的**完全停止**，而 FapHero 的"休息"大多是 1–3 秒的间隙。
若按次计数，一部作品动辄十几次"刹车"，递减额度很快被用光。

改成按累计时长：

- 10 秒以内不递减——"FapHero 能慷慨给出 10 秒总休息的都不多"；
- **满 10 秒立刻用掉第一次修正**（`k = 2K·0.85`），之后每 20 秒再降一档；
- 这条主要是**给作弊玩家**准备的（大量暂停会迅速耗尽减速额度）。

实测：参考1-SBT 06 全长 835 秒，累计有效休息只有 **16 秒**，只够 1 档（`k = 2K×0.85`）。由于参考1-SBT 06 同时是标定锚点，这一档的实际影响很小：它的分数从 113.1 变为 113.2，其他作品因 K 重新求解而变动不到 0.1%。

### 3.1 Bustos 六段数据（回落律的依据）

Bustos 等 2023（[PMC10136197](https://pmc.ncbi.nlm.nih.gov/articles/PMC10136197/)），
481 名早泄男性，"最多 5 次停顿"：

| 刺激段 | 均值 ± SD | 中位数 (IQR) | 停顿段 | 均值 ± SD |
|---|---:|---:|---|---:|
| Start 1 | 92.14 ± 74.70 | 76.0 (31–136) | Stop 1 | 25.37 ± 16.94 |
| Start 2 | 42.35 ± 35.52 | 31.0 (15–60) | Stop 2 | 25.68 ± 17.60 |
| Start 3 | 38.16 ± 34.05 | 27.0 (13–53) | Stop 3 | 22.99 ± 17.08 |
| Start 4 | 29.77 ± 30.91 | 20.0 (7–43) | Stop 4 | 17.37 ± 24.52 |
| Start 5 | 20.07 ± 30.36 | 8.0 (0–30) | Stop 5 | 9.63 ± 19.56 |
| Start 6 | 13.71 ± 26.93 | 0 (0–16) | | |

**正确的反推方式**：每次停顿「恢复的余量」= 下一段时长 × 增速 `u`。
用 `u = 0.5/92.14 = 0.00543/s` 换算：

| 刹车 | 下一段时长 | 恢复的余量 | 占 0.5 的比例 | 停顿时长 | `k_n` | 比值 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 42.35 s | 0.230 | **46%** | 25.37 | 0.00906 | — |
| 2 | 38.16 | 0.207 | **41%** | 25.68 | 0.00806 | 0.890 |
| 3 | 29.77 | 0.162 | **32%** | 22.99 | 0.00703 | 0.872 |
| 4 | 20.07 | 0.109 | **22%** | 17.37 | 0.00627 | 0.892 |
| 5 | 13.71 | 0.074 | **15%** | 9.63 | 0.00772 | 1.231 |

恢复能力是**平滑递减**（46% → 41% → 32% → 22% → 15%），不存在断崖。

**注意每个比值用到哪几段**：`k_n` 要用 Start n+1，所以

| 比值 | 用到 | 退出率 |
|---|---|---|
| `k₂/k₁ = 0.890` | Start 1, 2, 3 | 0 / 0 / 0 |
| `k₃/k₂ = 0.872` | Start 2, 3, **4** | 0 / 0 / **13.3%** |
| `k₄/k₃ = 0.892` | Start 3, **4**, **5** | 0 / 13.3% / **43%** |
| `k₅/k₄ = 1.231` | Start 4, 5, **6** | 13.3% / 43% / **62%** |

**只有 `0.890` 是完全无偏的**。`0.872` 与 `0.892` 都吃进了 Start 4 的生存偏差：
Start 4 的均值 29.77 s 只统计了走到这一步的 417 人，而他们是射精较慢的一批，
所以该均值**偏高** → `k₃`、`k₄` 偏高 → 比值被拉向 1 → **ρ 被高估**。

`k₅/k₄ = 1.231 > 1` 是另一回事：第 5 次停顿设计 30 秒、实际只有 9.63 秒
（被试在停顿过程中射了），属于**截断污染**，与生存偏差无关。

因此：唯一无偏估计是 **ρ = 0.890**（单比值、无误差棒），真实值应**低于**它。
取 **ρ = 0.85** 作为悲观值——低于无偏估计且给生存偏差留余量。
合理的置信区间大致是 **0.80–0.89**。

> 三点注意：后三段的均值有**生存偏差**（43%–62% 已被筛掉）；
> 后两次停顿的时长被实验截断（均值只有 17 和 10 秒）；
> 分布严重右偏（均值 ≫ 中位数）。前三次无退出，可信；后两次仅作参考。

**关键换算**：Bustos 的刺激强度 `u = 0.0054/s`，衰减 `k = 0.0085/s`。
参考1-SBT 06 的平均增速只有 `0.00074/s`，直接搬 0.0085 会让衰减成为增速的 11 倍。
所以回落速率必须**与刺激强度同比缩放**——取 `k_1 = 2K`。

## 4. 标定

基准不用任何人的单次表现，而是**作品 + 规则**：

> 参考1-SBT 06 的规则规定 **12:20（740 s）到 12:52 允许射精**。

## 附录 A：公式速查

```
E = 0.5; total_rest = 0; n = 0; started = False
for each dt:
    th = max(0, 1.0 - 2.0*(E - 0.5))
    if th <= 0 or r >= th:
        if not started: started = True
        E += K*((r-th)/(3-th))**1.2*dt
    elif started:
        E -= 2K*0.85**n*(1 - r/th)*dt                  (E>0.5, E<1)
E_clamped = max(0.5, E)
S = 100*(E_clamped - 0.5)/0.5

# HMV
r_bar = N/T; g = max(0,(r_bar-1.0)/2.0)**1.2; S = 100*(T/679)*g
# 挑战者
phi = S_ref(t)/100; 上限 = 80*phi
```
